# 경희대 오늘 뭐 먹지?

경희대학교 국제캠퍼스 학생회관의 오늘·내일 식단을 모바일에서 빠르게 확인하는 정적 웹앱 프로토타입입니다.

## 로컬 실행

```bash
npx serve .
```

## 배포

GitHub Pages에서 **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)`를 게시합니다.

## 자동 갱신

GitHub Actions가 매주 월요일 08:10 KST에 생협 식단 원문 이미지 변경을 확인합니다. 공식 메뉴가 이미지로만 게시되므로 현재 프로토타입은 마지막 검증 JSON을 안전하게 유지합니다. 완전 자동 메뉴 텍스트 변환에는 OCR 단계가 추가로 필요합니다.
